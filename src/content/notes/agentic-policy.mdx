I study how agents organize their own acquisition of robot skills: identifying what they need to learn, choosing demonstrations, simulation, or real-world trials, and using feedback to improve their policies. The aim is to turn costly physical experience into reliable skills that can be retained and reused.

I am a core contributor to [ACE-CaP-0: Real-World Code-as-Policies in the Era of Experience](https://acerobotics2025.github.io/ACE-CaP/). The project explores how a coding agent can request robot demonstrations and use simulation on demand while developing code policies through real-world feedback. The resulting programs are frozen for evaluation and execute with runtime perception and control, without a human or coding agent in the loop.

My broader interest is in agents that actively direct this learning process. The mechanisms can include program revision, parameter optimization, memory, or skill accumulation; the central questions are what experience to acquire, how to learn from it, and what capability remains available afterward.
